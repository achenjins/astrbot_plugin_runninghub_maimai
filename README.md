## 环境要求

| 项目 | 要求 |
| --- | --- |
| AstrBot | ≥ 4.13.0；Pages 管理页需 ≥ 4.24.2 |
| 机器人平台 | NapCat / OneBot v11 |
| RunningHub 账号 | 国内站或海外站均可，两边 Key 不通用 |
| Python 依赖 | `requests`（安装步骤会一并处理） |

> [!WARNING]
> RunningHub 按次扣费，建议装好后先配置「访问控制」。自动撤回仅 NapCat / OneBot v11 生效。

## 安装

```bash
cd <AstrBot目录>/data/plugins
git clone https://github.com/achenjins/astrbot_plugin_runninghub_maimai.git astrobt-runninghub
cd astrobt-runninghub
pip install -r requirements.txt
```

装好后在 AstrBot WebUI 启用 / 重载插件。

## 快速开始

### 1. 填写 API Key

使用邀请码注册可得 500 RH 币，下方链接已自动带上邀请码。

| 站点 | 注册 | API Key 页面 |
| --- | --- | --- |
| 国内站 | [注册（带邀请码）](https://www.runninghub.cn?inviteCode=8cq8uhl8) | [打开 API Key 页](https://www.runninghub.cn/enterprise-api/consumerApi?inviteCode=8cq8uhl8) |
| 海外站 | [注册（带邀请码）](https://www.runninghub.ai?inviteCode=bvhsaqdr) | [打开 API Key 页](https://www.runninghub.ai/enterprise-api/consumerApi?inviteCode=bvhsaqdr) |

在插件配置中填「国内 API Key」或「国外 API Key」。**两边 Key 不通用。**

**还需要在配置页面选择模型提供商**：识别用模型和提示词扩写用模型。留空会回退到当前会话 / 默认模型；若都没有可用模型，识别改用启发式规则、提示词扩写回退原文，建议显式选择。

### 2. 识别工作流

```text
/wf国外工作流 <工作流ID> <名称>
/wf国内工作流 <工作流ID> <名称>
```

看到「识别成功」后，在配置页或 Pages 里删掉不需要的节点（避免误触发无关能力，也少绕弯路）。

### 3. 运行

```text
/wf运行 <工作流名> <描述>
```

例如：

```text
/wf运行 文生图 原神刻晴
```

需要文件时机器人会引导上传；不想传就回「跳过剩余」。

一次完整的对话大致是这样（示意）：

```text
你：/wf运行 文生图 原神刻晴
机器人：请上传参考图，或回复「跳过剩余」
你：跳过剩余
机器人：任务已提交，完成后自动发回结果
```

## Pages 可视化管理

需要 AstrBot 4.24.2+，入口：插件详情 → Pages → `workflow-editor`。旧版 AstrBot 没有 Pages 入口，用插件配置页的「工作流列表 + 输入节点列表」动态表单。

- **工作流配置**：新建 / 编辑 / 删除工作流和输入节点，拖动排序、搜索、按国内外筛选；可填用途说明、输出类型，单独开关「允许聊天调用」，可编辑参数还能设置类型、范围和可选值；LLM 扩写模板支持上传、预览、选择。
- **任务面板**：显示排队位置、当前阶段、等待时间、耗时、RH 币消耗、送达数量和错误详情；可按状态筛选，每 5 秒自动刷新，直接取消、恢复查询或补发。
- **余额面板**：页面顶部显示国内外余额（RH 币 / 运行中任务 / 钱包），可手动刷新。

配置修改点「保存配置」后生效，插件热更新；模板和记录存在 `data/plugin_data/<插件目录>/`，更新插件不丢。

## 常用命令

| 命令 | 作用 |
| --- | --- |
| `/wf运行 <工作流名> [描述]` | 运行工作流 |
| `/wf中断` | 中断输入会话，或按编号取消任务 |
| `/wf状态 [任务编号]` | 查看本会话任务，恢复对已有任务的查询 |
| `/wf补发 [任务编号]` | 补发已生成的结果，不重新生成 |
| `/wf核对 <任务编号> <平台编号|未创建>` | 仅管理员，核对提交未确认的任务 |
| `/wf工作流` | 列出已配置工作流 |
| `/wf国内工作流 <ID> [名称]` | 识别国内站工作流 |
| `/wf国外工作流 <ID> [名称]` | 识别海外站工作流 |
| `/wf详细国内工作流 <ID> [名称]` | LLM 详细识别国内站工作流 |
| `/wf详细国外工作流 <ID> [名称]` | LLM 详细识别海外站工作流 |
| `/wf 保存提示词` / `/wf 提示词重跑` / `/wf 提示词` | 保存、重跑和选择已保存的扩写提示词 |
| `/wf 上传提示词` / `/wf 上传提示词模板` | 上传提示词或扩写模板 |

`<参数>` 必填，`[参数]` 可选。完整语法、示例、参数约定和各命令细节见 [命令说明](docs/命令说明.md)。

## 自然语言触发

工作流默认开启「允许聊天调用」，直接说话就能用，不用记命令：

```text
帮我画一只甘雨，蓝色长发，全身立绘
```

- 当前消息或引用消息里的图会直接用上；多张图说「第一张当主体，第二张当风格」，没说清用途会先问。
- 能接着上次结果改：「上次那张背景换成蓝色」。插件按会话记住最近用过和生成的图，默认 5 张（0–20 可调，设 0 关闭）。
- 说「画我的头像」就用 QQ 头像，群里也能用群头像。
- 结果发回后机器人会按当前语气再回一句，可在配置里关掉。
- 也能直接管任务：「取消刚才那个」「第二张没收到，再发一次」。

关掉某工作流的「允许聊天调用」即可排除它；新增或改名后重载插件生效。

## 排队与任务恢复

- 默认最多同时跑 2 个任务，名额满了就排队（默认最多排 10 个；「最多排队数」设为 0 表示不排队）。
- 任务状态会落盘：插件重载或重启后，排队任务接着跑，已提交到平台的任务继续跟踪并把结果发回来。排队期间用到的参考图会单独存一份，不依赖聊天缓存，缓存过期也不影响。
- 提交时平台没回应、无法确认任务是否创建，任务会冻结名额且**不会自动重提**，由管理员用 `/wf核对` 处理，详见 [命令说明](docs/命令说明.md)。

## FAQ

- **识别报 API Key 未填写？** 国内工作流用「国内 API Key」，海外用「国外 API Key」。
- **自然语言不触发？** 检查工作流是否开启了「允许聊天调用」；新增或改名工作流后重载插件。
- **重载插件后任务会丢吗？** 排队任务接着跑，已提交的任务继续跟踪；生成好的结果可以用 `/wf补发` 再发。
- **任务提交后一直没动静？** 先发 `/wf状态` 查看；显示「提交未确认」时由管理员用 `/wf核对` 处理，插件不会自动重提。
- **自动撤回没生效？** 仅 NapCat / OneBot v11 平台支持。
- **找不到 Pages 入口？** Pages 需要 AstrBot 4.24.2+，旧版请用插件配置页的动态表单。
- **最近图片记录能关吗？** 「最近图片数量」设为 0 即关闭并清空，不影响正常出图。
- **更新插件后数据会丢吗？** 模板、提示词、任务记录和图片都在 `data/plugin_data/<插件目录>/` 下，详见 [命令说明](docs/命令说明.md)。
